# Deskless Feedback (Issues + Discussions)

Welcome! This repo is the public tracker for **Deskless** bug reports, feature requests, and community discussion.

> **Note:** This is **not** the Deskless source code repository. It exists only for feedback and tracking.

## Where should I post?

### ✅ Use **Issues** for actionable items
Create an Issue if you have:
- 🐞 A reproducible **bug**
- ✨ A specific **feature request**
- 🔧 A clear **improvement** that can be tracked to completion

**Tip:** Please include platform + Deskless version + steps to reproduce whenever possible.

### 💬 Use **Discussions** for conversation
Start a Discussion for:
- 🙋 Questions / “How do I…?”
- 💡 Brainstorming & early ideas
- 🧵 Sharing workflows / suggestions without a clear action item
- 🗳️ Gauging interest before turning something into an Issue

👉 Go to Discussions: https://github.com/Lowcountry-Code-Labs-LLC/deskless-feedback/discussions

## Supported platforms
Deskless 3.0 is live on iPhone, iPad and Android.

- **iOS / iPadOS**: [Download on the App Store](https://apps.apple.com/us/app/deskless/id6756940860)
- **Android**: [Get it on Google Play](https://play.google.com/store/apps/details?id=app.deskless)

## Security issues
Please **do not** report security vulnerabilities in Issues or Discussions.

Instead, use **private vulnerability reporting**:
https://github.com/Lowcountry-Code-Labs-LLC/deskless-feedback/security/advisories/new

More info: see `SECURITY.md`.

## What to include in bug reports
- Platform (iOS / iPadOS / Android)
- Deskless version (Settings/About)
- OS version (e.g., iOS 26.1)
- Exact steps to reproduce
- What you expected vs what happened
- Screenshots/logs (please **redact** personal data, tokens, repo URLs, etc.)

Thanks for helping make Deskless better ❤️
